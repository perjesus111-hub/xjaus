# Security reporting / Informes de seguridad

1.2.4 is unreleased source; no maintenance window or response SLA is promised. Report privately using GitHub’s private vulnerability reporting **if enabled**, or ask a maintainer for a private channel without disclosing details. Do not open a public issue with vulnerability details, credentials or account data. Provide the affected commit/version, platform, impact and sanitized observations. Use synthetic data and coordinate public disclosure with the maintainers.

En español: usa un canal privado, indica versión y plataforma y comparte solo evidencia saneada. Si no hay un canal privado visible, solicita uno sin publicar detalles. Consulta [privacidad](PRIVACY.md).

Build and fixture checks do not approve artifacts. Review [release preparation](docs/RELEASE-PREPARATION.md) before separately authorizing package verification, signing or publication.
