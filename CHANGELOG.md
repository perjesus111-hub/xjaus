# Changelog

All notable changes are documented here from published Git tags. Dates and entries below are derived from the repository history; this file does not retroactively alter releases.

## [1.0.2] - 2026-10-20

### Added

- Gamepad navigation for the stream menu with a visible focused option and A/B hints.
- Windows x64 NSIS installer packaging.
- Release checksums for Linux AppImage, RPM, DEB, and Windows installer artifacts.

### Changed

- Stream input is neutralized while the stream menu is open and restored when it closes.
- Windows packaging includes the Rust sidecar and avoids embedding personal build paths.

## [1.0.1] - 2026-10-19

### Changed

- First-launch language follows the operating system instead of forcing Spanish.

## [1.0.0] - 2026-10-19

### Added

- Initial published Electron and Rust-sidecar release with Linux packaging.
